Path B WAF example (crsEnable: false):

  apiVersion: waf.kubewaf.io/v1beta1
  kind: WAF
  metadata:
    name: my-app
    namespace: {{ .Release.Namespace }}
  spec:
    engine: ModSecurity
    crsEnable: false
    crs:
      paranoiaLevel: 1
      inboundAnomalyThreshold: 5
    targetRef:
      group: gateway.networking.k8s.io
      kind: HTTPRoute
      name: my-app
    ruleRefs:
      - kind: RuleSet
        name: ruleset-api
        group: waf.kubewaf.io
        version: v1beta1
{{- if .Values.extras.enabled }}
      - kind: RuleSet
        name: {{ .Values.extras.rulesetName }}
        group: waf.kubewaf.io
        version: v1beta1
{{- end }}

Requires the kubewaf operator + CRDs (charts/kubewaf). Verify:

  kubectl get secrules,rulesets -n {{ .Release.Namespace }}

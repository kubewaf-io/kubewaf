## Quick report

Email **[hello@kubewaf.io](mailto:hello@kubewaf.io)** with subject `SECURITY: …`,  
or use GitHub private vulnerability reporting on this repository when enabled.

Please do **not** open public issues for exploitable vulnerabilities.
